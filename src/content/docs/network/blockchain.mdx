These pages explain how Aptos works: accounts and resources, how transactions change state, how Move and Block-STM execute those transactions, and how validators, staking, and governance keep the network running.

For implementation details, read the [Aptos white paper](/network/blockchain/aptos-white-paper), the [research papers](https://aptoslabs.com/research), and the [aptos-core](https://github.com/aptos-labs/aptos-core) source. For hands-on work, start with [Your First Transaction](/build/guides/first-transaction) and the [Move Book](https://aptos-labs.github.io/move-book/).
