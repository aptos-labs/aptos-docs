如果你已使用 ASDF 或 Mise 包管理器，可按以下步骤安装 Aptos CLI。

## 使用 ASDF 安装

<Steps>
  1. 确认已安装 [ASDF](https://asdf-vm.com/)。

  2. 安装 Aptos CLI 插件。

     ```sh
     asdf plugin add aptos https://github.com/gregnazario/asdf-aptos.git
     ```

  3. 安装 Aptos CLI。

     ```sh
     asdf install aptos latest
     ```

  4. （可选）安装特定版本。

     ```sh
     # 本地安装
     asdf install aptos 7.9.0

     # 全局安装
     asdf global aptos 7.9.0
     ```

  5. 验证安装是否成功。

     ```sh
     aptos help
     ```

     这些帮助信息也是特定命令的实用详细指南。
</Steps>

## 使用 Mise 安装

<Steps>
  1. 确认已安装 [Mise](https://mise.jds.dev/)。

  2. 安装 Aptos CLI 插件。

     ```sh
     mise plugin add aptos https://github.com/gregnazario/asdf-aptos.git
     ```

  3. 安装 Aptos CLI。

     ```sh
     mise install aptos
     ```

  4. （可选）安装特定版本。

     ```sh
     mise install aptos@7.9.0
     ```

  5. 将该工具加入本地配置。

     ```sh
     mise use aptos
     ```

  6. 验证安装是否成功。

     ```sh
     aptos help
     ```

     这些帮助信息也是特定命令的实用详细指南。
</Steps>
