## Federated Keyless

[AIP-96](https://github.com/aptos-foundation/AIPs/blob/main/aips/aip-096-federated-keyless-accounts.md)：Federated Keyless 是 Aptos Keyless 的扩展。在保持去中心化的同时，它支持更多 OpenID Connect（OIDC）提供商，而不局限于通过 JWK 共识在 `0x1::jwks` 中列入允许名单的提供商。只要项目使用受支持的身份与访问管理（IAM）提供商进行用户认证，Federated Keyless 就支持通过该 IAM 提供商认证用户，例如 Auth0 或 AWS Cognito。

进一步来说，Federated Keyless 支持：

1. 扩展认证方式\
   a. dApp 可以使用 IAM 支持的所有认证方式，包括电子邮件/SMS OTP，以及 Discord、Naver、X 等社交登录集成市场。以 Auth0 为例，可参阅其[市场](https://marketplace.auth0.com/)。

2. 兼容现有账户系统\
   a. IAM 也支持自定义认证，因此应用可以使用自己的用户名/密码体系（参阅 Cognito [文档](https://docs.aws.amazon.com/cognito/latest/developerguide/amazon-cognito-user-pools-authentication-flow.html)和 Auth0 [文档](https://auth0.com/blog/Custom-Authentication-With-Auth0/)）。应用可以直接使用已在 IAM 中配置的现有账户系统，也可以将现有账户系统迁移至 IAM，以生成兼容 Keyless 的 JWT。
