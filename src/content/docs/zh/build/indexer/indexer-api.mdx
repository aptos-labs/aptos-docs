Aptos Labs 托管公开版本的 Indexer GraphQL API，任何人都可以使用它获取链上交易、同质化资产和代币的基础历史数据和聚合数据。

您可以在下方查看所需网络的 Hasura Explorer，手动探索该 API。

也可以通过下方 GraphQL 端点访问 API。有关各字段或表中数据格式的更多信息，请参阅[表参考页面](/zh/build/indexer/indexer-api/indexer-reference)。

## SDK 访问（主要方式）

使用 Indexer 的主要方式是通过 [TypeScript SDK](/zh/build/sdks/ts-sdk/fetch-data-via-sdk) 访问。

TypeScript SDK 会自动处理速率限制，并能根据所需数据在 [Fullnode REST API](/zh/build/apis/fullnode-rest-api) 访问和 Indexer 访问之间无缝切换。

## GraphQL API 端点（直接访问）

如果需要直接向 Aptos Labs 托管的 Indexer API 发出 GraphQL 查询，请使用以下端点：

- **Mainnet：** `https://api.mainnet.aptoslabs.com/v1/graphql`
- **Testnet：** `https://api.testnet.aptoslabs.com/v1/graphql`
- **Devnet：** `https://api.devnet.aptoslabs.com/v1/graphql`

### 速率限制

阅读 [Geomi 文档](https://geomi.dev/docs/admin/billing)，了解适用于 Aptos Labs 托管 Indexer API 的速率限制。

若需要更高的速率限制，请考虑以下方案：

1. 从 [Geomi](https://geomi.dev/) 获取 API 密钥。有关 API 密钥的更多信息，请参阅 [Geomi 文档站点](https://geomi.dev/docs/api-keys)。
2. 自行运行 Aptos Indexer API。请参阅[这里](/zh/build/indexer/txn-stream/self-hosted)的自托管指南。
