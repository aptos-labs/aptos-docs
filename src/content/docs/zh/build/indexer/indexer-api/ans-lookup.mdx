`getNameFromAddress` 会查找给定账户已注册的域名。例如，用户可以在 Aptos Name Service 中注册账户，使其关联到 `love.apt`。请访问 [https://www.aptosnames.com/](https://www.aptosnames.com/) 了解更多。

<Aside type="caution">
  此查询只返&#x56DE;_&#x6D3B;&#x8DC3;_&#x540D;称。名称注册若未续期可能过期，这可能解释某些空结果。
</Aside>

<Aside type="note">
  亲自试用！您可以在编辑器底部自定义变量。
</Aside>

<GraphQLEditor
  query={`query getNameFromAddress($registered_address: String) {
  current_aptos_names(
    where: {
      registered_address: { _eq: $registered_address }
      is_active: { _eq: true }
    }
    order_by: [
      { is_primary: desc }
      { last_transaction_version: desc }
      { expiration_timestamp: desc }
    ]
    limit: 1
  ) {
    domain
    subdomain
  }
}`}
  variables={`{
  "registered_address": "0xca4349ce902a656570a4f344cc8f360fb13fd41b5fae77bcc9ee82252d67539e"
}`}
/>

#### 变量：

- `$registered_address`：**String** — 要查找关联活跃域名的账户地址。例如：`"0xca4349ce902a656570a4f344cc8f360fb13fd41b5fae77bcc9ee82252d67539e"`。
