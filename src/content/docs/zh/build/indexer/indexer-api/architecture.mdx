Aptos Indexer 存储来自链上的数据（通过交易流服务）。它会索引交易、同质化资产、代币、集合、账户、ANS（Aptos Name Service）名称等基础数据。应用可通过 Indexer API 查询这些数据。

Aptos Labs 托管一个免费版本的 Indexer API，帮助社区访问以下数据：

1. 历史数据，例如：[哪些交易影响了此账户？](/zh/build/indexer/indexer-api/account-transactions)
2. 聚合数据，例如：[该质押池中有多少委托人？](/zh/build/indexer/indexer-api/get-delegators)
3. 最适合通过查询搜索的特定信息，例如：[一个账户拥有哪些 NFT？](/zh/build/indexer/indexer-api/get-nfts)

Indexer 使用[交易流服务](/zh/build/indexer/txn-stream)和使用 [Indexer SDK](/zh/build/indexer/indexer-sdk) 编写的自定义处理器，将丰富的表更新到数据库中。随后，它公开 API，供 Aptos 应用访问整合后的数据。

当您的需求超出 Aptos 托管 Indexer API 提供的数据时，应使用 [Indexer SDK](/zh/build/indexer/indexer-sdk) 创建自定义处理器。

编写自定义处理器可以帮助您：

1. 访问不同类型的数据。
2. 存储 Aptos Labs 托管 Indexer API 未保存的额外信息。
3. 更改处理交易的方式。

如果希望以服务形式运行自己的 Indexer API，请了解如何[托管自己的 Indexer](/zh/build/indexer/indexer-api/self-hosted)。
