Indexer API 通过 GraphQL 提供链上交易、NFT、Fungible Asset、委托质押和账户数据。可在 [Indexer API](/zh/build/indexer/indexer-api) 页面访问接口。

本页已对照主网 GraphQL schema（`https://api.mainnet.aptoslabs.com/v1/graphql`）核对。下文包含 `public_key_auth_keys`、`current_objects`、`confidential_asset_activities` 等新表。

<Aside type="caution">
  在生产服务中依赖数据表前，请检查本页末尾的弃用表说明；已弃用的表应按提示迁移。
</Aside>

<Aside type="note">
  名称带 \_by\_pk 后缀的表由系统自动生成，便于按主键查询；请在本页搜索不带后缀的基础表名。
</Aside>

# Indexer 数据表参考

## 筛选（使用 where 子句）

为确保查询高效，请查看每张表的索引。复合 B-tree 索引由多列组成，查询使用索引列的最左前缀时性能最佳。
