## 前置条件

请先阅读[创建处理器](/zh/build/indexer/indexer-sdk/documentation/create-processor)、[创建步骤](/zh/build/indexer/indexer-sdk/documentation/steps)和[连接步骤](/zh/build/indexer/indexer-sdk/documentation/connect-steps)，这些指南将帮助您设置处理器并连接处理器步骤。

## 如何设置 config.yaml

要运行处理器，需要创建 `config.yaml` 文件。`config.yaml` 文件格式应遵循您在 `IndexerProcessorConfig` 中定义的格式。例如，如果使用 [aptos-indexer-processor-example](https://github.com/aptos-labs/aptos-indexer-processor-example/blob/main/aptos-indexer-processor-example/src/config/indexer_processor_config.rs) 中的 `IndexerProcessorConfig`，基本的 `config.yaml` 如下：

```yaml
health_check_port: 8085
server_config:
  processor_config:
    type: "events_processor"
  transaction_stream_config:
    indexer_grpc_data_service_address: "https://grpc.mainnet.aptoslabs.com:443"
    starting_version: 0
    auth_token: "{AUTH_TOKEN}"
    request_name_header: "events-processor"
  db_config:
    postgres_connection_string: postgresql://postgres:@localhost:5432/example
```

`processor_config` 字段应与 `IndexerProcessorConfig` 中 `ProcessorConfig` 的定义相匹配，`db_config` 和 `DbConfig` 也是如此。

`TransactionStreamConfig` 是 `transaction-stream` crate 提供的配置。它要求设置 `indexer_grpc_data_service_address`、`auth_token` 和 `request_name_header`。要获取 `indexer_grpc_data_service_address` 和 `auth_token`，请遵循[此指南](/zh/build/indexer/txn-stream/aptos-hosted-txn-stream)。

`TransactionStreamConfig` 还支持更多可选字段来调整与[交易流](/zh/build/indexer/txn-stream)的连接；详情请参阅[这里](https://github.com/aptos-labs/aptos-indexer-processor-sdk/tree/main/aptos-indexer-processors-sdk/transaction-stream)。

## 运行处理器

设置好 `config.yaml` 后，可通过以下命令运行处理器：

```shellscript
cd /path/to/your/processor/crate
cargo run --release -- -c config.yaml
```
