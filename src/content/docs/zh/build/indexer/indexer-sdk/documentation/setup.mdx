如果从头创建自定义处理器，建议遵循[快速入门指南](/zh/build/indexer/indexer-sdk/quickstart)。快速入门指南提供模板处理器，并包含所有这些设置。

如果要将现有处理器迁移到 Indexer SDK，请执行以下步骤。

将 `aptos-indexer-processor-sdk` 添加到 `Cargo.toml`。

```toml
[dependencies]
aptos-indexer-processor-sdk = { git = "https://github.com/aptos-labs/aptos-indexer-processor-sdk.git", rev = "aptos-indexer-processor-sdk-v1.0.0" }
```

`aptos-indexer-processor-sdk` 包含以下功能：

1. `postgres_full`：将 Postgres 与处理器集成的接口层。
2. `testing_framework`：用于测试处理器的端到端测试框架。如果要为处理器编写测试，请将此功能添加到 crate。
