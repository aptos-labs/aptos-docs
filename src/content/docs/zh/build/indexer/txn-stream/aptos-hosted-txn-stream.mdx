如果您正在运行 [Indexer API](/zh/build/indexer) 的自有实例，或 [Indexer SDK](/zh/build/indexer/indexer-sdk) 自定义处理器，则必须能够访问交易流服务的实例。本页介绍如何使用 Aptos Labs 托管交易流服务。

## 端点

除非另有说明，所有端点均位于 GCP us-central1。

- **Mainnet：** grpc.mainnet.aptoslabs.com:443
- **Testnet：** grpc.testnet.aptoslabs.com:443
- **Devnet：** grpc.devnet.aptoslabs.com:443

阅读 [Geomi 文档](https://geomi.dev/docs/admin/billing)可了解该服务的速率限制。

## 通过 API 密钥授权

要使用 Labs 托管交易流服务，您必须拥有 API 密钥。获取 API 密钥的步骤如下：

1. 前往 [https://geomi.dev](https://geomi.dev)。
2. 登录并选择“API Resource”。
3. 创建新密钥。您会在第一个表格中看到 API 密钥机密。

您可以通过设置 `Authorization` HTTP 标头（[MDN](https://developer.mozilla.org/en-US/docs/Web/HTTP/Headers/Authorization)）提供 API 密钥。例如，使用 curl：

```shellscript filename="Terminal"
curl -H 'Authorization: Bearer aptoslabs_yj4donpaKy_Q6RBP4cdBmjA8T51hto1GcVX5ZS9S65dx'
```

有关 API 密钥的更多信息，请参阅 [Geomi 文档站点](https://geomi.dev/docs/api-keys)。

若要全面了解如何使用交易流服务，请参阅下游系统的文档：
