Kaptos 是一个 Kotlin **多平台** SDK，可在多种平台上与 Aptos 区块链交互。
它为数据请求、交易提交等操作提供**一致**的 API，使应用能共享业务逻辑并实现跨平台开发。
SDK 内置**异步** Aptos 客户端，可顺畅地与区块链交互。

Kaptos 还为 JVM、Android、iOS、JS、Linux、macOS 和 Windows 提供平台专用 SDK。

## 功能

- **类型安全**：SDK 完全类型安全，并为所有操作提供丰富的类型。
- **表达力强**：Kaptos 提供简洁且富有表达力的 DSL 风格 API，用于构建交易。
- **多平台**：使用共享业务逻辑编写跨平台应用。
- **一致的 API**：所有操作在各平台上都采用统一且一致的 API。
- **支持 BCS**：SDK 默认使用 BCS 对交易进行序列化和反序列化。
- **异步**：所有区块链操作均为异步操作。
- **可配置**：SDK 为所有平台提供高度可配置的客户端。

  Kaptos 目前仍在开发中，欢迎在[这里](https://github.com/mcxross/kaptos/issues)提供反馈。
</Aside>

## 执行交易

下面的示例展示如何使用 Kotlin SDK 执行交易。该代码片段采用最新的精简 API，将构建、签名和提交合并为一次调用。

```kotlin
val result = aptos.execute(signer = alice) {
  function = "0x1::coin::transfer"
  typeArgs("0x1::aptos_coin::AptosCoin")
  args(bob.accountAddress, 1_000_000UL)
}
```

SDK 也为常见交易操作提供预构建方法。例如，您可以使用 `transferCoinTransaction` 方法生成两个账户之间的转账交易：

```kotlin
val txn = aptos.transferCoinTransaction(
     alice.accountAddress,
     bob.accountAddress,
     SEND_AMOUNT
   )
```

然后可以对此交易进行[签名](/zh/build/sdks/community-sdks/kotlin-sdk/building-transactions#签名交易)，并[提交](/zh/build/sdks/community-sdks/kotlin-sdk/building-transactions#提交交易)。
