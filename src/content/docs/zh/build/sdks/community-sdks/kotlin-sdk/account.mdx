Kaptos 支持多种账户类型，以便处理 Aptos 网络上各种身份验证方案。本页面介绍了如何创建和管理：

- 传统 Ed25519 (`Ed25519Account` / `Account.generate()`)
- 使用统一验证的 SingleKey (`SingleKeyAccount`)
- 用于阈值签名 (threshold signing) 的 MultiKey (`MultiKeyAccount`)
- 通过 `Aptos` 工厂方法由 SDK 管理的账户
- 通过 [账户抽象](/zh/build/sdks/community-sdks/kotlin-sdk/account-abstraction) 实现的自定义身份验证方案

## 传统账户 (Ed25519)

传统账户类型代表使用 Ed25519 签名方案的账户。

```kotlin
val legacy = Account.generate()

val fromPrivateKey = Account.fromPrivateKey(Ed25519PrivateKey("0x..."))
```

## SingleKey 账户 (Ed25519 或 Secp256k1)

统一的 `SingleKeyAccount` 支持 Ed25519 或 Secp256k1 签名方案。

```kotlin
val ed25519Single = SingleKeyAccount.generate(scheme = SigningSchemeInput.Ed25519)
val secp256k1Single = SingleKeyAccount.generate(scheme = SigningSchemeInput.Secp256k1)

val fromKey = SingleKeyAccount(
  privateKey = Ed25519PrivateKey("0x...")
)
```

## MultiKey 账户 (阈值签名)

`MultiKeyAccount` 允许您要求从定义的公钥集合中获得多个签名（阈值签名）以对交易进行身份验证。

```kotlin
val signerA = SingleKeyAccount.generate(scheme = SigningSchemeInput.Ed25519)
val signerB = SingleKeyAccount.generate(scheme = SigningSchemeInput.Secp256k1)
val signerC = SingleKeyAccount.generate(scheme = SigningSchemeInput.Ed25519)

val multiKeyAccount = MultiKeyAccount.fromPublicKeysAndSigners(
  publicKeys = listOf(signerA.publicKey, signerB.publicKey, signerC.publicKey),
  signaturesRequired = 2,
  signers = listOf(signerA, signerC),
)
```

## SDK 管理的账户

当使用 `Aptos` 客户端时，您可以使用自动管理私钥生命周期的工厂方法，确保它们被安全处理并自动关闭。

```kotlin
aptos(AptosConfig(network = Network.DEVNET)) {
  val alice = account()  // 默认是 Ed25519
  val bob = singleKeyAccount(SigningSchemeInput.Secp256k1)
  // 当此代码块退出时，私钥将被自动清除
}
```

您还可以从解析的或未解析的 AIP-80 格式的密钥实例化账户：

```kotlin
// 从 AIP-80 字符串创建
val fromString = aptos.ed25519Account("ed25519-priv-0x...")

// 从解析的 AIP-80 密钥创建
val fromParsed = aptos.account(Aip80PrivateKey.parse("ed25519-priv-0x..."))
```

### AIP-80 私钥格式

AIP-80 定义了一种将私钥表示为字符串的标准格式，使用前缀（`ed25519-priv-`、`secp256k1-priv-`）后接十六进制编码的密钥。这使得密钥在不同的语言和生态系统之间更具可移植性，同时保留了它们的类型。

## 账户发现

您可以通过链上公钥来发现账户，或者通过签名者衍生出拥有的账户。

```kotlin
val accounts = aptos.accounts.findByPublicKey(publicKey)
val ownedAccounts = aptos.accounts.deriveOwned(signer)
```

## 链上账户创建

在本地生成账户仅创建了凭证。若要真正在链上使用该账户，必须通过为其充值来进行创建。

```kotlin
aptos.faucet.fund(alice.accountAddress, 100_000_000UL)
```

## 账户抽象

若需通过 Move 模块实现自定义验证逻辑，或从外部钱包（如支持“使用 Solana 登录”的 Solana 钱包）派生 Aptos 账户，请参阅 [账户抽象指南](/zh/build/sdks/community-sdks/kotlin-sdk/account-abstraction)。
