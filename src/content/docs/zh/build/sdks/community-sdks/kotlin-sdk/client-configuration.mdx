尽管 **Kaptos** 在所有支持的平台上都提供与 Aptos 交互的**一致接口**，它也为不同客户端提供共享和平台专用的配置选项。

借助这些配置选项，您可以按需自定义客户端行为。创建 `ClientConfig` 对象，并在创建 `Aptos` 客户端时将其传入 `AptosSettings` 对象即可设置这些选项：

```kotlin
val clientConfig = ClientConfig(followRedirects = false, retryOnServerErrors = 3)
val client = Aptos(AptosConfig(AptosSettings(clientConfig = clientConfig)))
```

本页将介绍各平台可用的配置选项。

### 共享配置

`followRedirects` — 决定客户端是否跟随重定向的布尔值。默认值为 `true`。

`retryOnServerErrors` — 发生服务器错误时重试请求的次数。默认值为 `—1`，即不重试。

`requestTimeout` — 请求超时时间，单位为毫秒。默认值为 `10_000`。

`maxRetries` — 请求最多重试的次数。默认值为 `-1`，即不重试。

`agent` — 指定连接所用用户代理的 `String`。默认为 `Kaptos/{PLATFORM}`。

`likeAgent` — 指定连接所用用户代理的 `UserAgent` 枚举值。

`proxy` — 指定连接所用代理服务器的 `String`。

`cache` — 决定是否缓存响应的布尔值。默认值为 `false`。

### JVM 配置

`pipelining` — 决定客户端是否使用流水线的布尔值。默认值为 `false`。

`pipelineMaxSize` — 流水线中的最大请求数。默认值为 `20`。

`maxConnectionsPerRoute` — 每个路由的最大连接数。默认值为 `100`。

`maxConnectionsCount` — 最大连接数。默认值为 `100`。

`connectTimeoutMillis` — 与服务器建立连接的超时时间，单位为毫秒。默认值为 `10_000`。

`keepAliveTime` — 保持连接存活的时间，单位为毫秒。默认值为 `5_000`。

`connectAttempts` — 尝试连接服务器的次数。默认值为 `5`。

`connectTimeout` — 与服务器建立连接的超时时间，单位为毫秒。默认值为 `10_000`。

### Android 配置

`followSslRedirects` — 决定客户端是否跟随 SSL 重定向的布尔值。默认值为 `true`。

`connectTimeoutMillis` — 与服务器建立连接的超时时间，单位为毫秒。默认值为 `10_000`。

`readTimeoutMillis` — 从服务器读取数据的超时时间，单位为毫秒。默认值为 `10_000`。

`writeTimeoutMillis` — 向服务器写入数据的超时时间，单位为毫秒。默认值为 `10_000`。

`maxRetries` — 请求最多重试的次数。默认值为 `-1`，即不重试。

`connectTimeout` — 与服务器建立连接的超时时间，单位为毫秒。默认值为 `10_000`。

### Apple（iOS、macOS）配置

Apple 平台目前没有任何平台专用配置选项。

### Web 配置

Web 平台目前没有任何平台专用配置选项。

### Linux 配置

`connectTimeout` — 与服务器建立连接的超时时间，单位为毫秒。默认值为 `10_000`。

### Windows 配置

`connectTimeout` — 与服务器建立连接的超时时间，单位为毫秒。默认值为 `10_000`。
