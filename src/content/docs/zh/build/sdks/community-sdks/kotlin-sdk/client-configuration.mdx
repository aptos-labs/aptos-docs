`AptosConfig` 类是 Aptos Kotlin SDK 的单一配置入口点。在创建 `Aptos` 客户端实例时，您需要向其传递一个 `AptosConfig` 对象。

## 基础配置

```kotlin
val aptos = Aptos(AptosConfig(network = Network.DEVNET))
```

## AptosConfig 字段

`AptosConfig` 数据类包含以下字段：

- `network: Network` - 要连接的 Aptos 网络：`MAINNET`、`TESTNET`、`DEVNET`、`LOCAL` 或 `CUSTOM`（默认：`DEVNET`）。
- `endpoints: AptosEndpoints` - 覆盖默认的 `fullNode`、`indexer` 和 `faucet` URLs。
- `commonHeaders: Map<String, String>` - 应用于所有请求的 HTTP 标头。
- `fullNode: AptosEndpointConfig` - 全节点的每个端点标头和身份验证配置。
- `indexer: AptosEndpointConfig` - 索引器的每个端点配置。
- `faucet: AptosEndpointConfig` - 水龙头的每个端点配置。
- `requestTimeoutMillis: Long` - 请求超时时间，以毫秒为单位（默认：`10,000`）。
- `indexerWaitTimeoutMillis: Long` - 索引器等待超时时间，以毫秒为单位（默认：`10,000`）。
- `archivalFallback: Boolean` - 请求失败时是否回退到归档节点（默认：`true`）。
- `namesContractAddress: AccountAddress?` - 自定义的 Aptos 命名服务 (ANS) 合约地址。
- `transactionDefaults: TransactionDefaults` - 交易的默认 `maxGasAmount` 和 `expirationSecondsFromNow`。
- `transport: AptosTransport?` - 注入自定义的 HTTP 传输实现。
- `abiCachePolicy: AbiCachePolicy` - 用于构建 payload 的 Move ABI 缓存策略。

## 自定义端点

要使用自定义网络或特定的端点，请使用 `Network.CUSTOM` 并在 `endpoints` 中提供 URLs：

```kotlin
val aptos = Aptos(AptosConfig(
  network = Network.CUSTOM,
  endpoints = AptosEndpoints(
    fullNode = "https://my-node.example.com/v1",
    indexer = "https://my-indexer.example.com/v1/graphql",
  ),
))
```

## 每端点身份验证

您可以为各个端点提供特定的标头，例如授权令牌：

```kotlin
val aptos = Aptos(AptosConfig(
  network = Network.MAINNET,
  fullNode = AptosEndpointConfig(
    headers = mapOf("Authorization" to "Bearer my-token"),
  ),
))
```

## 交易默认值

为该客户端构建的所有交易设置默认的 Gas 和过期时间设置：

```kotlin
val aptos = Aptos(AptosConfig(
  transactionDefaults = TransactionDefaults(
    maxGasAmount = 5_000_000UL,
    expirationSecondsFromNow = 30UL,
  ),
))
```

## 托管生命周期

`Aptos` 类实现了 `AutoCloseable` 以清理资源，如 HTTP 客户端和任何 SDK 托管的账户。SDK 提供了一个 `aptos { }` 块用于托管作用域：

```kotlin
aptos(AptosConfig(network = Network.DEVNET)) {
  // client and SDK-owned accounts close automatically after this block
}

// Or manual lifecycle:
val client = Aptos(AptosConfig(network = Network.DEVNET))
try {
  // use client
} finally {
  client.close()
}
```

## 注入传输层

如果您想要管理自己的 HTTP 客户端或使用不同的传输层，您可以通过 `AptosConfig` 注入一个 `AptosTransport` 实现。请注意，如果您注入了一个由调用者拥有的传输层，当 `Aptos` 实例关闭时，SDK 不会自动关闭它。
