Kaptos 提供了多个命名空间服务，用于从 Aptos 区块链读取数据。

## 基于结果的处理

所有的 SDK 操作都返回一个 `AptosResult<T>` 密封接口。您可以使用 `when` 表达式或类似 `.map()`、`.onSuccess()` 和 `.onFailure()` 的扩展函数来处理结果。

```kotlin
when (val result = aptos.ledger.info()) {
  is AptosResult.Success -> println("Version: ${result.value.version}")
  is AptosResult.Failure -> println("Error: ${result.error.message}")
}
```

有关错误处理的更多详情，请参阅[响应处理](/zh/build/sdks/community-sdks/kotlin-sdk/fetch-data/response-handling)文档。

## 读取账本数据

使用 `ledger` 服务查询网络信息或特定区块：

```kotlin
// Get current ledger state
val state = aptos.ledger.info().getOrNull()!!

// Get a block by height
val block = aptos.ledger.blockAtHeight(1UL).getOrNull()!!
```

## 读取账户数据

使用 `accounts` 服务查找账户元数据和资源：

```kotlin
val address = AccountAddress.fromString("0x1")
val accountInfo = aptos.accounts.get(address).getOrNull()!!
```

## 读取余额

`accounts` 服务提供了一种便捷的方法来获取传统代币和同质化资产的余额：

```kotlin
// Coin balance
val aptBalance = aptos.accounts.getBalance(
  address,
  AccountAsset.coin("0x1::aptos_coin::AptosCoin"),
).getOrNull()!!

// Fungible asset balance
val faBalance = aptos.accounts.getBalance(
  address,
  AccountAsset.fungibleAsset("0xa"),
).getOrNull()!!

// 或通过视图函数简写读取代币余额
val coinBalance = aptos.views.callOf<AptosCoin>(
  function = "0x1::coin::balance",
  address,
).getOrNull()!!
```

## 通过 Move 视图函数读取

使用 `views` 服务来执行 Move 模块中定义的视图函数。`callOf` 简写语法会自动根据链上 ABI 验证参数，并将标准 Kotlin 类型强制转换为对应类型：

```kotlin
// 不带参数的简洁视图调用
val result = aptos.views.callOf(
  function = "0x1::chain_id::get",
).getOrNull()!!

// 带有具体化泛型类型参数和推断参数的视图调用
val balance = aptos.views.callOf<AptosCoin>(
  function = "0x1::coin::balance",
  address,
).getOrNull()!!
```

如果您需要传递未经过 SDK 验证或 ABI 查找的原始参数，请使用 `callRaw`：

```kotlin
val result = aptos.views.callRaw(
  function = "0x1::coin::balance",
  typeArguments = listOf("0x1::aptos_coin::AptosCoin"),
  arguments = listOf(JsonPrimitive("0x1")),
).getOrNull()!!
```
