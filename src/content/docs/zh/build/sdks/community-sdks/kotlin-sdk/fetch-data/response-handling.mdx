所有操作都返回 `AptosResult<T>`，它表示 `Success` 或 `Failure`。这确保了显式的错误处理。

### 使用 `when` 表达式

```kotlin
when (val result = aptos.ledger.info()) {
  is AptosResult.Success -> println("Ledger version: ${result.value.version}")
  is AptosResult.Failure -> println("Error: ${result.error.message}")
}
```

### 扩展函数

- `.map { }` - 转换成功值
- `.flatMap { }` - 链接另一个 AptosResult 操作
- `.fold(onSuccess = {}, onFailure = {})` - 归约为单个结果类型
- `.getOrNull()` - 返回值或 null
- `.getOrElse { fallback }` - 返回值或从错误派生后备值
- `.onSuccess { }` - 成功时的副作用，返回原结果不变
- `.onFailure { }` - 失败时的副作用，返回原结果不变
- `.isSuccess` / `.isFailure` - 布尔值检查

```kotlin
val version = aptos.ledger.info()
  .map { it.version }
  .getOrElse { 0UL }
```

```kotlin
aptos.faucet.fund(alice.accountAddress, 100_000_000UL)
  .onSuccess { println("Funded successfully") }
  .onFailure { println("Funding failed: ${it.message}") }
```

```kotlin
val balance = aptos.accounts.getBalance(address, asset)
  .fold(
    onSuccess = { "Balance: $it" },
    onFailure = { "Error: ${it.message}" },
  )
```

### 错误分类 (AptosError)

`AptosError` 是一个具有多个变体的密封接口：

- `AptosError.Transport` - 网络/HTTP 错误
- `AptosError.Api` - REST API 错误（包含 `errorCode`，可选的 `vmErrorCode`）
- `AptosError.Indexer` - GraphQL/索引器错误
- `AptosError.Validation` - 客户端验证失败
- `AptosError.Serialization` - BCS/JSON 编码错误
- `AptosError.Crypto` - 密钥生成或签名错误
- `AptosError.Timeout` - 请求或等待超时
- `AptosError.Cancelled` - 操作已取消
- `AptosError.UnsupportedFeature` - 功能不可用

```kotlin
when (val result = aptos.transactions.submitAndWait(signer, payload)) {
  is AptosResult.Success -> println("Confirmed")
  is AptosResult.Failure -> when (result.error) {
    is AptosError.Api -> println("API error: ${result.error.errorCode}")
    is AptosError.Timeout -> println("Timed out")
    else -> println("Other: ${result.error.message}")
  }
}
```
