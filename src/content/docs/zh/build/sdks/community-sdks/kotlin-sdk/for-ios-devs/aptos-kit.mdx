**AptosKit** 是一个用于与 Aptos 区块链交互的 Swift SDK，提供简洁易用的接口。

该 SDK 是面向 [Kaptos](/zh/build/sdks/community-sdks/kotlin-sdk)（Aptos 的 Kotlin SDK）的 Swift 包导出。它将 iOS 二进制文件作为依赖项提供给使用原生 Swift 项目的 iOS 开发者。

<Aside type="note">
  **AptosKit** 目前仍在开发中，欢迎在[这里](https://github.com/mcxross/swift-aptos/issues)提供反馈。
</Aside>

## 安装

要安装 **AptosKit**，请在 `Package.swift` 文件中添加以下内容：

```swift filename="Package.swift"
dependencies: [
    .package(url: "https://github.com/mcxross/swift-aptos.git", .upToNextMajor(from: <version>))
]
```
