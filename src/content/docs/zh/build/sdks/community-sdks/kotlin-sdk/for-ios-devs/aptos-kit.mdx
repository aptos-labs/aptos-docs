**AptosKit** 是一个用于与 Aptos 区块链交互的 Swift SDK。
它提供了一个简单易用的界面来与 Aptos 区块链进行交互。

此 SDK 是 [Kaptos](/zh/build/sdks/community-sdks/kotlin-sdk)（一个用于 Aptos 区块链的 Kotlin SDK）的 Swift 包导出。它通过将其 iOS 二进制文件作为依赖项提供给开发原生 Swift 项目的 iOS 开发者来构建。

AptosKit 反映了 Kotlin SDK 的命名空间服务 API 结构。`Aptos` 客户端暴露了 `ledger`、`accounts`、`transactions`、`faucet` 等服务，为 Swift 开发者提供了与 Kotlin Multiplatform 中可用的相同模式。

<Aside type="note">
  **AptosKit** 目前仍在开发中，请在[这里](https://github.com/mcxross/swift-aptos/issues)提供反馈意见。
</Aside>

## 安装

要安装 **AptosKit**，请将以下内容添加到你的 `Package.swift` 文件中：

```swift filename="Package.swift"
dependencies: [
    .package(url: "https://github.com/mcxross/swift-aptos.git", .upToNextMajor(from: <version>))
]
```
