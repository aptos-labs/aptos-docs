本指南将引导你完成 **AptosKit** 的设置并在 Aptos 区块链上获取数据。

<Steps>
  1. 安装 SDK

     **AptosKit** 作为 Swift 包提供。将以下内容添加到你的 `Package.swift` 文件中：

     ```swift filename="Package.swift"
     dependencies: [
       .package(url: "https://github.com/mcxross/swift-aptos.git", .upToNextMajor(from: <version>))
     ]
     ```

  2. 导入 SDK

     ```swift filename="Main.swift"
     import AptosKit
     ```

  3. 创建配置

     `AptosConfig` 是所有客户端设置的单一入口点。设置目标网络和任何可选的覆盖参数。

     ```swift filename="Main.swift"
     let aptosConfig = AptosConfig(network: .devnet)
     ```

  4. 创建 Aptos 客户端

     `Aptos` 对象是所有区块链交互的入口点。其带有命名空间的服务（`ledger`、`accounts`、`transactions` 等）反映了 Kotlin API 的结构。

     ```swift filename="Main.swift"
     let aptos = Aptos(config: aptosConfig)
     ```

  5. 获取链 ID

     ```swift filename="Main.swift"
     let state = try await aptos.ledger.info()
     print("Chain ID: \(state.chainId)")
     ```

     恭喜你！你已成功设置 **AptosKit** 并从 Aptos 区块链读取了账本数据。
</Steps>

## 完整示例

```swift filename="Main.swift"
import SwiftUI
import AptosKit

struct ContentView: View {
  @State private var chainId: String? = nil

  var body: some View {
    VStack {
      if let chainId = chainId {
        Text("Chain ID: \(chainId)")
      } else {
        Text("Fetching Chain ID...")
      }
    }
    .padding()
    .onAppear {
      fetchChainId()
    }
  }

  private func fetchChainId() {
    Task {
      do {
        let aptosConfig = AptosConfig(network: .devnet)
        let aptos = Aptos(config: aptosConfig)

        let state = try await aptos.ledger.info()
        await MainActor.run {
          self.chainId = "\(state.chainId)"
        }
      } catch {
        print("Failed to get chain ID: \(error)")
        await MainActor.run {
          self.chainId = "Error"
        }
      }
    }
  }
}
```
