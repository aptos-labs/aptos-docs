[Aptos Unity SDK](https://github.com/aptos-labs/Aptos-Unity-SDK) 是 [Aptos SDK](/zh/build/sdks) 的 .NET 实现，兼容 Unity 的 .NET Standard 2.0 和 .NET 4.x。该 SDK 的目标是为开发者提供一套工具，以便使用 Unity 游戏引擎和 Aptos 区块链基础设施构建多平台应用（移动端、桌面端、Web、VR）。

请参阅文章 [Aptos Labs brings Web3 to Gaming with its new SDK for Unity developers](https://medium.com/aptoslabs/aptos-labs-brings-web3-to-gaming-with-its-new-sdk-for-unity-developers-e6544bdf9ba9)，以及 Unity SDK README 的[技术详情](https://github.com/aptos-labs/Aptos-Unity-SDK#technical-details)部分，了解 Aptos Unity SDK 为游戏开发者提供的所有功能。

## 用户流程

Aptos Unity SDK 支持以下用例：

- _渐进式引导流程_：用户可通过电子邮件登录游戏。在此流程中，交易会被代理，Aptos 使用分布式密钥系统。之后，用户可以按需迁移至完全托管的钱包。
- _游戏内非托管钱包集成_：游戏开发者可选择允许用户在游戏中创建完整的非托管钱包。
- _游戏外非托管钱包集成_：游戏开发者可允许用户在游戏中连接桌面钱包或移动钱包，或从父钱包无缝创建 burner 钱包。

## 安装 Unity SDK

您可以通过 `unitypackage` 或 [Unity Package Manager](https://docs.unity3d.com/Manual/Packages.html) 安装 Unity SDK。

### 通过 unitypackage 安装

1. 启动 Unity。
2. 从 [Unity Asset Store](https://assetstore.unity.com/packages/decentralization/aptos-sdk-244713) 下载最新 `Aptos.Unity.unitypackage` 文件。
3. 单击 **Assets** → **Import Packages** → **Custom Package**，然后选择下载的文件。

### 通过 Unity Package Manager 安装

1. 打开 [Unity Package Manager](https://docs.unity3d.com/Manual/upm-ui.html) 窗口。
2. 单击顶部状态栏中的添加 **+** 按钮。
3. 从下拉菜单中选择 _Add package from git URL_。
4. 输入 URL _[https://github.com/aptos-labs/Aptos-Unity-SDK.git](https://github.com/aptos-labs/Aptos-Unity-SDK.git)_，然后单击 **Add**。
