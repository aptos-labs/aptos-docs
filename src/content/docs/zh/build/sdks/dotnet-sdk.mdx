<Aside type="danger" title="已弃用">
  Aptos .NET SDK 已弃用且不再维护。新项目请使用
  [TypeScript SDK](/zh/build/sdks/ts-sdk)、
  [Python SDK](/zh/build/sdks/python-sdk)、[Go SDK](/zh/build/sdks/go-sdk)
  或 [Rust SDK](/zh/build/sdks/rust-sdk)。
</Aside>

在 .NET 应用中集成 Aptos Web3 功能。此 SDK 的目标是为开发者提供一套工具，以便在兼容的游戏引擎和平台上构建多平台应用。

**支持的功能**

- 二进制规范序列化（BCS）编码与解码
- 支持 Ed25519、SingleKey、MultiKey 和 Keyless 签名人
- 用于构建、签名和提交交易的工具
- 对 Aptos Fullnode 和 Indexer API 的抽象
- 支持 Aptos 名称（ANS）解析和查询

## 安装

.NET SDK 可通过 [NuGet](https://www.nuget.org/packages/Aptos) 获取。

您可以使用以下命令安装 .NET SDK：

```shellscript
dotnet add package Aptos
```
