Aptos .NET SDK 提供创建和管理 Ed25519 账户的简便方法。本指南提供创建或导入现有账户的代码片段。

## 创建 Ed25519Account

Ed25519Account 用于签名交易并与区块链交互。

### 使用私钥

要从私钥生成账户，需要创建 Ed25519PrivateKey 对象并将其传给 Ed25519Account 构造函数。私钥可以使用 string 或 byte\[] 表示。

```csharp
var privateKey = new Ed25519PrivateKey("0x1234...abcdef");
var account = new Ed25519Account(privateKey);
```

### 使用助记词

要从助记词生成账户，可以使用 Ed25519Account.FromDerivationPath，并传入助记词和派生路径。Aptos 生态系统通常使用的派生路径是 `m/44'/637'/0'/0'/0'`。

```csharp
var account = Ed25519Account.FromDerivationPath(
    "m/44'/637'/0'/0'/0'",
    "apple banana cat dog elephant fox ..."
);
```

### 生成随机账户

要创建随机账户，可以使用 `Account.Generate()` 方法。

```csharp
var account = Account.Generate();
```
