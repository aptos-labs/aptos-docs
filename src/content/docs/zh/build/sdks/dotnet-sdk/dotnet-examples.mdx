Aptos .NET SDK 提供许多示例来帮助您开始使用 SDK。您可以在 [aptos-labs/aptos-dotnet-sdk](https://github.com/aptos-labs/aptos-dotnet-sdk) 仓库中找到这些示例。

<br />

<LinkCard href="https://github.com/aptos-labs/aptos-dotnet-sdk/tree/main/Aptos.Examples" title="Aptos .NET SDK 示例" description=".NET SDK 的示例应用。" target="_blank" />

<Steps>
  1. 安装 .NET

     要运行示例，需要安装 .NET SDK。您可以从 [dotnet.microsoft.com](https://dotnet.microsoft.com/en-us/download) 网站下载 .NET SDK。

  2. 克隆仓库

     运行以下命令克隆仓库：

     ```shellscript
     git clone https://github.com/aptos-labs/aptos-dotnet-sdk.git
     ```

  3. 运行示例

     进入 `Aptos.Examples` 目录并运行 `dotnet run --framework net8.0` 命令：

     ```shellscript
     cd Aptos.Examples
     dotnet run --framework net8.0
     ```

  4. 选择示例

     运行示例时，系统会提示您选择一个示例。您可以输入要运行的示例编号，或使用方向键导航。

     ![示例演示](~/images/dotnet-examples/select-example.png)
</Steps>
