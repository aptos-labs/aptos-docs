本指南将带你完成 Aptos .NET SDK 的集成过程。要将 Aptos SDK 安装到 Godot 项目，需要将 Aptos SDK 加入 Godot 项目的 .csproj 文件。

<Steps>
  1. 找到 .csproj

     在 Godot 项目根目录中找到 .csproj 文件。该文件用于配置 Godot 项目，并由 Godot 构建系统使用。可在 Godot 编辑器中点击 res\://，选择 Open in File Manager 来找到它。

     > 如果找不到 .csproj 文件，可以创建 .cs 文件并构建应用一次；它应会自动生成。

     <br />

     <div className="border dark:border-white/30 w-fit rounded-md overflow-clip shadow-md max-w-lg">
       ![在文件管理器中打开](~/images/dotnet-sdk/open-in-file-manager.png)
     </div>

  2. 添加 Aptos NuGet 包

     将以下行加入 `.csproj` 文件的 `<ItemGroup>` 部分。如果该部分不存在，请创建该部分。

     ```xml filename=".csproj"
     <ItemGroup>
       <PackageReference Include="Aptos" Version="0.0.2-beta" />
     </ItemGroup>
     ```

     文件应类似如下：

     ```xml filename=".csproj" {10-14}
     <Project Sdk="Godot.NET.Sdk/4.3.0">
       <PropertyGroup>
         <TargetFramework>net6.0</TargetFramework>
         <TargetFramework Condition=" '$(GodotTargetPlatform)' == 'android' ">net7.0</TargetFramework>
         <TargetFramework Condition=" '$(GodotTargetPlatform)' == 'ios' ">net8.0</TargetFramework>
         <EnableDynamicLoading>true</EnableDynamicLoading>
         <RootNamespace>AptosSDKExample</RootNamespace>
       </PropertyGroup>

       <!-- START: Add these lines -->
       <ItemGroup>
         <PackageReference Include="Aptos" Version="0.0.1-beta" />
       </ItemGroup>
       <!-- END -->

     </Project>
     ```

  3. 使用 Aptos SDK

     在 C# 脚本中导入 Aptos 命名空间，然后使用 SDK。

     ```csharp filename="Example.cs" {3-3,9-9,12-16}
     using Godot;
     using System;
     using Aptos;

     public partial class Example : Node
     {
         public override void _Ready()
         {
             PrintLedgerInfo();
         }

         async void PrintLedgerInfo() {
             var client = new AptosClient(Networks.Mainnet);
             var ledgerInfo = await client.Block.GetLedgerInfo();
             GD.Print(ledgerInfo.BlockHeight);
         }

     }
     ```
</Steps>
