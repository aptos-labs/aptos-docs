本指南将带您完成 Aptos .NET SDK 的集成过程。

<Steps>
  1. 安装 Aptos Unity SDK

     #### 选项 1：通过 Unity Package Manager（UPM）导入

     1. 打开 Package Manager 窗口（Window | Package Manager）
     2. 单击窗口左上角的 + 按钮，选择 _Add package from git URL..._
     3. 输入以下 URL，然后单击 Add 按钮

     ```shellscript
     https://github.com/aptos-labs/unity-sdk.git?path=/Packages/com.aptoslabs.aptos-unity-sdk
     ```

     #### 选项 2：通过 unitypackage 导入

     1. 前往 [`aptos-labs/unity-sdk Releases`](https://github.com/aptos-labs/unity-sdk/releases)，下载最新版本。
     2. 将 `.unitypackage` 文件拖放到 Unity 项目中。

  2. 使用 Aptos SDK

     在 C# 脚本中导入 `Aptos` 命名空间并使用 SDK。

     ```csharp {2-2,8-8,11-15}
     using UnityEngine;
     using Aptos;

     class Example : MonoBehaviour
     {
         public void Start()
         {
             PrintLedgerInfo();
         }

         async void PrintLedgerInfo() {
             var client = new AptosUnityClient(Networks.Mainnet);
             var ledgerInfo = await client.Block.GetLedgerInfo();
             Debug.Log(ledgerInfo.BlockHeight);
         }

     }
     ```
</Steps>
