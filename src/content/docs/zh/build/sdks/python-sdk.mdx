Aptos 提供一个轻度维护的官方 Python SDK。它可通过 [PyPi](https://pypi.org/project/aptos-sdk/) 获取，源代码位于 [aptos-python-sdk GitHub 仓库](https://github.com/aptos-labs/aptos-python-sdk)。Python SDK 的许多功能与 [TypeScript SDK](/zh/build/sdks/ts-sdk) 一致。Python SDK 的主要目的，是帮助 Python 开发者快速熟悉 Aptos，并配合 Aptos 教程使用。

## 安装 Python SDK

Python SDK 可通过 `pip`、源代码安装，或嵌入项目：

### 使用 pip 安装

要通过 `pip` 安装：

```shellscript filename="Terminal"
pip3 install aptos-sdk
```

`aptos-sdk` 将安装在本地 site-packages 目录中。例如在 macOS 上，您可以在 `~/Library/Python/3.8/lib/python/site-packages/aptos_sdk` 目录中找到 `aptos-sdk`。

### 从源代码安装

要从源代码安装：

```shellscript filename="Terminal"
git clone https://github.com/aptos-labs/aptos-python-sdk
pip3 install . --user
```

### 通过嵌入安装

要将 Python SDK 嵌入现有 Python 项目：

```shellscript filename="Terminal"
cd /path/to/python/project
cp -r /path/to/aptos-python-sdk aptos-sdk
```
