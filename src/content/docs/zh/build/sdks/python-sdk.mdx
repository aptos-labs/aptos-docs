## 安装 Python SDK

Aptos 在 [PyPI](https://pypi.org/project/aptos-sdk/) 上提供官方 Python SDK，源代码位于
[aptos-python-sdk GitHub 仓库](https://github.com/aptos-labs/aptos-python-sdk)。
该 SDK 需要 **Python 3.12+**。

使用 `pip` 安装：

```shellscript filename="Terminal"
pip install aptos-sdk
```

或从源代码安装：

```shellscript filename="Terminal"
git clone https://github.com/aptos-labs/aptos-python-sdk
cd aptos-python-sdk
pip install .
```

<Aside type="note">
  新代码应使用 v2 API（`aptos_sdk.v2`）。同一软件包中仍保留 v1 API（`RestClient`、
  来自 `aptos_sdk.account` 的 `Account.generate()`），供现有教程使用。请参阅 SDK
  仓库中的
  [v1 到 v2 迁移指南](https://github.com/aptos-labs/aptos-python-sdk/blob/main/MIGRATION.md)。
</Aside>
