交易可用于更改链上数据或触发事件。通常，交易从构建到链上执行分为五个步骤：构建、模拟、签名、提交和等待。

<Aside type="note">
  在这些示例中，`aptos` 是使用 `Aptos(AptosConfig(network=Network.DEVNET))` 创建的 `Aptos` 客户端。
</Aside>

<Steps>
  1. 构建

     构建交易时需要指定：

     1. **发送方账户。**<br />此账户通常支付交易的 Gas 费用。有关由另一账户支付交易费用的信息，请参阅[赞助交易](/zh/build/sdks/python-sdk/building-transactions/sponsoring-transactions)。
     2. **链上调用的函数。**<br />这是执行交易时将触发的链上智能合约入口函数标识符。
     3. **类型参数和参数。**<br />函数运行所需的任何数据。

     可按如下方式为单个账户构建：

     ```python filename="build_a_transaction.py"
     from aptos_sdk.v2.bcs import Serializer
     from aptos_sdk.v2.transactions import EntryFunction, TransactionArgument, TransactionPayload
     from aptos_sdk.v2.types import StructTag, TypeTag

     payload = EntryFunction.natural(
         "0x1::aptos_account",
         "transfer_coins",
         [TypeTag(StructTag.from_str("0x1::aptos_coin::AptosCoin"))],
         [
             TransactionArgument(bob.address, Serializer.struct),
             TransactionArgument(1_000, Serializer.u64),
         ],
     )
     raw_txn = await aptos.transaction.build(
         sender=alice.address,
         payload=TransactionPayload(payload),
     )
     ```

     <Aside type="note">
       请优先使用 `0x1::aptos_account::transfer_coins`，而不是 `0x1::coin::transfer`。如果接收方尚无 `CoinStore`，`transfer_coins` 会创建它。
     </Aside>

     #### 构建选项

     可通过向 `aptos.transaction.build` 传递关键字参数来自定义交易执行方式。一些最常用的选项包括：

     1. `max_gas_amount` - 限制你愿意为执行此交易支付的 Gas 数量。
     2. `gas_unit_price` - 可以指定高于最低值的每单位 Gas 价格，以便 Aptos 网络以更高优先级执行。
     3. `expiration_timestamps_secs` - 指定交易必须在此时间前执行，否则将被取消。
     4. `replay_protection_nonce` - 设置后，SDK 会构建不消耗序列号的无序交易。

     若未显式指定，SDK 会为这些值提供合理默认值。也可以在 `AptosConfig` 上设置默认值。

  2. 模拟（可选）

     Aptos 链上的每笔交易都会根据网络机器执行该交易所需的工作量收取 Gas 费用。为估算相关成本，可以在提交前模拟交易。

     <Aside type="note">
       模拟只需要账户的公钥，因为它不会影响账本的实际状态。
     </Aside>

     可使用 `aptos.transaction.simulate` 执行模拟，如下所示：

     ```python filename="build_a_transaction.py"
     simulation_result = await aptos.transaction.simulate(raw_txn, alice.public_key)
     ```

  3. 签名

     交易构建完成且费用看起来合理后，即可签名。签名必须来自发送方账户。

     ```python filename="build_a_transaction.py"
     signed_txn = aptos.transaction.sign(raw_txn, alice)
     ```

  4. 提交

     交易签名后，可使用 `aptos.transaction.submit` 提交到网络，如下所示：

     ```python filename="build_a_transaction.py"
     txn_hash = await aptos.transaction.submit(signed_txn)
     ```

  5. 等待

     最后，可使用 `aptos.transaction.wait_for_transaction` 并指定刚提交的交易哈希来等待结果，如下所示：

     ```python filename="build_a_transaction.py"
     result = await aptos.transaction.wait_for_transaction(txn_hash)
     ```
</Steps>

对于 Coin 转账，`aptos.coin.transfer` 会封装构建、签名和提交：

```python
txn_hash = await aptos.coin.transfer(alice, bob.address, 1_000)
await aptos.transaction.wait_for_transaction(txn_hash)
```

也可以在手动构建后合并签名、提交和等待：

```python
result = await aptos.transaction.sign_submit_and_wait(raw_txn, alice)
```

## 完整 Python 示例

```python filename="build_a_transaction.py"
import asyncio

from aptos_sdk.v2 import Account, Aptos, AptosConfig, Network
from aptos_sdk.v2.bcs import Serializer
from aptos_sdk.v2.transactions import EntryFunction, TransactionArgument, TransactionPayload
from aptos_sdk.v2.types import StructTag, TypeTag

FUND_AMOUNT = 100_000_000
TRANSFER_AMOUNT = 1_000


async def main():
    async with Aptos(AptosConfig(network=Network.DEVNET)) as aptos:
        alice = Account.generate()
        bob = Account.generate()

        print("=== Addresses ===")
        print(f"Alice: {alice.address}")
        print(f"Bob:   {bob.address}")

        await aptos.faucet.fund_account(alice.address, FUND_AMOUNT)
        await aptos.faucet.fund_account(bob.address, 10_000_000)

        print("=== Initial Balances ===")
        print(f"Alice: {await aptos.coin.balance(alice.address)}")
        print(f"Bob:   {await aptos.coin.balance(bob.address)}")

        payload = EntryFunction.natural(
            "0x1::aptos_account",
            "transfer_coins",
            [TypeTag(StructTag.from_str("0x1::aptos_coin::AptosCoin"))],
            [
                TransactionArgument(bob.address, Serializer.struct),
                TransactionArgument(TRANSFER_AMOUNT, Serializer.u64),
            ],
        )
        raw_txn = await aptos.transaction.build(
            sender=alice.address,
            payload=TransactionPayload(payload),
        )

        simulation_result = await aptos.transaction.simulate(raw_txn, alice.public_key)
        print("=== Simulation ===")
        print(f"Gas used: {simulation_result[0]['gas_used']}")
        print(f"Status:   {simulation_result[0]['vm_status']}")

        result = await aptos.transaction.sign_submit_and_wait(raw_txn, alice)
        print(f"Success: {result['success']}")

        print("=== Final Balances ===")
        print(f"Alice: {await aptos.coin.balance(alice.address)}")
        print(f"Bob:   {await aptos.coin.balance(bob.address)}")


asyncio.run(main())
```

## 总结

在链上构建并发送交易包含以下 5 个步骤：

1. **构建**交易。
2. **模拟**成本。（可选）
3. **签名**交易（如果模拟成本看起来合理）。
4. **提交**交易到网络。
5. **等待**链验证并更新。
