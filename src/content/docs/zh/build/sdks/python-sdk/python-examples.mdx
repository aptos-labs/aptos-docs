## 代码片段

SDK 仓库中的 [`v2/examples` 文件夹](https://github.com/aptos-labs/aptos-python-sdk/tree/main/v2/examples)
包含许多可按需定制的代码片段。从 PyPI 安装 `aptos-sdk` 时，请从 `aptos_sdk.v2` 导入相同 API，而不是 `aptos_sdk_v2`。

| 示例                              | 说明                            |
| ------------------------------- | ----------------------------- |
| `transfer_apt.py`               | 两个账户之间的基本 APT 转账              |
| `different_key_types.py`        | Ed25519 与 Secp256k1 账户        |
| `multi_agent_transfer.py`       | 带有两个签名人的多代理交易                 |
| `sponsored_transaction.py`      | 由费用支付方赞助的交易                   |
| `orderless_transfer.py`         | 带重放保护 nonce 的无序交易             |
| `batch_orderless_transfers.py`  | 并行无序转账                        |
| `simulate_transaction.py`       | 提交前模拟交易                       |
| `fetch_on_chain_data.py`        | 账本信息、区块、资源和 View 函数           |
| `mnemonic_key_recovery.py`      | BIP-39 助记词生成和密钥派生             |
| `custom_coin_fungible_asset.py` | Coin API 与 Fungible Asset API |
| `script_transaction.py`         | Script payload 构造             |

v1 示例如 `transfer_coin.py` 和 `fee_payer_transfer_coin.py` 位于顶层 [`examples` 文件夹](https://github.com/aptos-labs/aptos-python-sdk/tree/main/examples)。新项目应使用 v2 示例。

<Aside type="note">
  请优先使用这些仓库示例，而不是复制旧博客中的代码片段。Python SDK v2 API
  是受支持的接口，examples 文件夹会跟踪当前 API。
</Aside>

### 如何运行示例

要运行其中一个 v2 示例脚本：

<Steps>
  1. 克隆仓库。

     ```shellscript filename="Terminal"
     git clone https://github.com/aptos-labs/aptos-python-sdk.git
     cd aptos-python-sdk
     ```

  2. 安装软件包和依赖。

     ```shellscript filename="Terminal"
     pip install .
     ```

  3. 运行示例。在 `v2/` 目录下，示例会导入 `aptos_sdk_v2`：

     ```shellscript filename="Terminal"
     cd v2
     python examples/transfer_apt.py
     ```
</Steps>
