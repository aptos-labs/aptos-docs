## 安装

Aptos 在 [Aptos-core GitHub](https://github.com/aptos-labs/aptos-core/tree/main/sdk) 仓库中提供官方的轻度支持 Rust SDK。要使用 Rust SDK，请直接在 `Cargo.toml` 中添加以下 git 仓库依赖和补丁：

```toml filename="Cargo.toml"
[dependencies]
aptos-sdk = { git = "https://github.com/aptos-labs/aptos-core", branch = "devnet" }

[patch.crates-io]
merlin = { git = "https://github.com/aptos-labs/merlin" }
x25519-dalek = { git = "https://github.com/aptos-labs/x25519-dalek", branch = "zeroize_v1" }
```

您还必须创建包含以下内容的 `.cargo/config.toml` 文件：

```toml filename=".cargo/config.toml"
[build]
rustflags = ["--cfg", "tokio_unstable"]
```

官方 Rust SDK 的源代码位于 [aptos-core GitHub 仓库](https://github.com/aptos-labs/aptos-core/tree/main/sdk)。
