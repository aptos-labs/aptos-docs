Rust SDK 可让你连接、探索并与 Aptos 区块链交互。你可以用它请求数据、发送交易、设置测试环境等。

## 安装 Rust SDK

Aptos 在 [aptos-rust-sdk GitHub](https://github.com/aptos-labs/aptos-rust-sdk)
仓库和 [crates.io](https://crates.io/crates/aptos-sdk) 上提供官方 Rust SDK。
将其添加到 `Cargo.toml`：

```toml filename="Cargo.toml"
[dependencies]
aptos-sdk = "0.7"
tokio = { version = "1", features = ["full"] }
anyhow = "1"
```

若要使用尚未发布的最新更改：

```toml filename="Cargo.toml"
[dependencies]
aptos-sdk = { git = "https://github.com/aptos-labs/aptos-rust-sdk", package = "aptos-sdk" }
```

该 SDK 需要 **Rust 1.95+**。与 `aptos-core` 中的旧版 crate 不同，此 SDK 不需要
git 补丁，也不需要 `.cargo/config.toml` 中的 `tokio_unstable` 标志。

<Aside type="note">
  如果此前依赖来自 `aptos-labs/aptos-core` 的 `aptos-sdk`，请参阅
  [迁移指南](https://github.com/aptos-labs/aptos-rust-sdk/blob/main/MIGRATION.md)。
  `LocalAccount` 现为 `Ed25519Account`，水龙头、Coin 和 REST 辅助方法均位于
  同一个 `Aptos` 客户端上。
</Aside>

### 功能标志

| 功能          | 默认 | 说明                       |
| ----------- | -- | ------------------------ |
| `ed25519`   | 是  | Ed25519 签名方案             |
| `secp256k1` | 是  | Secp256k1 ECDSA 签名       |
| `secp256r1` | 是  | Secp256r1（P-256）ECDSA 签名 |
| `mnemonic`  | 是  | BIP-39 助记词支持             |
| `indexer`   | 是  | GraphQL Indexer 客户端      |
| `faucet`    | 是  | 测试网水龙头集成                 |
| `bls`       | 否  | BLS12-381 签名             |
| `macros`    | 否  | 用于类型安全合约绑定的过程宏           |

最小构建：

```toml filename="Cargo.toml"
[dependencies]
aptos-sdk = { version = "0.7", default-features = false, features = ["ed25519"] }
```
