## 代码片段

SDK 仓库中的 [`examples` 文件夹](https://github.com/aptos-labs/aptos-rust-sdk/tree/main/crates/aptos-sdk/examples)
包含许多可按需定制的代码片段。

| 示例                           | 说明                          |
| ---------------------------- | --------------------------- |
| `transfer.rs`                | 账户之间的基本 APT 转账              |
| `view_function.rs`           | 只读 View 函数调用                |
| `simulation.rs`              | 提交前模拟交易                     |
| `sponsored_transaction.rs`   | 费用支付方（赞助）交易                 |
| `multi_agent.rs`             | 多签名人交易                      |
| `account_management.rs`      | 账户创建、助记词和密钥类型               |
| `indexer_queries.rs`         | 通过 GraphQL 查询 Aptos Indexer |
| `fungible_asset_transfer.rs` | 转移同质化资产                     |
| `orderless_transaction.rs`   | 无序（基于 nonce）交易              |

### 如何运行示例

要运行其中一个示例脚本：

<Steps>
  1. 克隆仓库。

     ```shellscript filename="Terminal"
     git clone https://github.com/aptos-labs/aptos-rust-sdk.git
     cd aptos-rust-sdk
     ```

  2. 使用所需功能运行示例。

     ```shellscript filename="Terminal"
     cargo run -p aptos-sdk --example transfer --features "ed25519,faucet"
     ```
</Steps>
