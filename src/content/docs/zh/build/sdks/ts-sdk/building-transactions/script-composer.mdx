## 概述

在基础 API 中,您只能为单个交易指定一个入口函数调用.而高级构建者可能希望在一个交易中调用多个 **public** Move 函数.Script Composer 可以实现这一点:你可以使用 `addBatchedCalls` 描述一系列调用,将一个调用的返回值传递给下一个调用,SDK 会将它们编译成单个脚本交易.

## 安装

将独立包与其 `@aptos-labs/ts-sdk` 和 WASM（`@aptos-labs/script-composer-pack`）对等依赖一起安装:

## 基本用法

从 `@aptos-labs/script-composer-sdk`（而不是 `@aptos-labs/ts-sdk`）导入 `BuildScriptComposerTransaction` 和 `CallArgument`:

```typescript filename="example.ts"
import { Aptos, AptosConfig, Network } from "@aptos-labs/ts-sdk";
import {
  BuildScriptComposerTransaction,
  CallArgument,
} from "@aptos-labs/script-composer-sdk";

const aptosConfig = new AptosConfig({ network: Network.TESTNET });
// 这里需要填写 sender 的地址
const sender = "0x1";

const tx = await BuildScriptComposerTransaction({
  sender,
  // 组合交易需要读取链上状态（模块 ABI 和字节码），因此需要传递目标网络的 AptosConfig
  aptosConfig,
  builder: async (composer) => {
    // 开始取出一些 Coin
    const coin = await composer.addBatchedCalls({
      function: "0x1::coin::withdraw",
      functionArguments: [CallArgument.newSigner(0), 1],
      typeArguments: ["0x1::aptos_coin::AptosCoin"],
    });

    // 将 coin 值传递给 0x1::coin::coin_to_fungible_asset 将代币
    // 转换为可替代资产。coin[0] 表示您添加的第一个调用的第一个返回值
    const fungibleAsset = await composer.addBatchedCalls({
      function: "0x1::coin::coin_to_fungible_asset",
      functionArguments: [coin[0]],
      typeArguments: ["0x1::aptos_coin::AptosCoin"],
    });

    // 存入从第二个调用转换得到的 fungibleAsset
    await composer.addBatchedCalls({
      function: "0x1::primary_fungible_store::deposit",
      functionArguments: [sender, fungibleAsset[0]],
      typeArguments: [],
    });
    return composer;
  },
});
```

> 请注意当前实例仅为参考如何使用 Script Composer 组合交易的过程中接收 public 函数的返回值，并传递给下一个函数

对于需要次级签名者（secondary signers）和/或费用支付者（fee payer）的交易，请改用同一包中的 `BuildScriptComposerMultiAgentTransaction`。对于仅有单个签名者的赞助交易，可以向 `BuildScriptComposerTransaction` 传递 `withFeePayer: true`。

## 交易处理

组合交易后，我们可以使用 `@aptos-labs/ts-sdk` 中的 签名交易 / 模拟交易 / 提交交易等接口:

我们用 模拟交易接口展示如何使用

```typescript filename="example.ts"
const aptos = new Aptos(aptosConfig);

const [simulateResult] = await aptos.transaction.simulate.simple({
  transaction: tx,
});

console.log("simulate_result: ", simulateResult);
```

## 技术原理

在底层,SDK 会调用 WASM 二进制文件（由 `@aptos-labs/script-composer-pack` 提供）将一系列 Move 调用编译为 `CompiledScript`.这将确保在构建过程中仍然遵循 Move 的类型和能力安全性.对于 SDK 用户而言,这意味着:

1. 能力安全性:
   a. 如果返回值不具备 Drop 能力,则该返回值需要被后续调用消费
   b. 如果返回值不具备 Copy 能力,则该返回值只能传递给后续调用一次
2. 调用者需要确保将正确的值作为参数传递给后续调用.在前述示例中,`0x1::coin::coin_to_fungible_asset` 函数需要接收一个 `Coin<AptosCoin>` 类型的参数.

这实现了 [AIP-102](https://github.com/aptos-foundation/AIPs/blob/main/aips/aip-102.md) 规范
