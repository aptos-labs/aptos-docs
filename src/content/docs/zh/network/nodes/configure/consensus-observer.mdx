共识观察者是一种新的数据传播技术，可降低 Aptos 全节点（即 VFN 和 PFN）的区块同步时间和交易延迟。研究显示，它可根据负载（即每秒交易数）使 Mainnet 的端到端交易延迟降低 10% 到 50%。

有关共识观察者的更多信息，请参阅 AIP：[AIP-93：共识观察者](https://github.com/aptos-foundation/AIPs/blob/main/aips/aip-93.md)。

<Aside type="tip">
  **公共全节点（PFN）**<br />
  本文所述的配置设置仅适用于公共全节点（PFN）。
  验证者和验证者全节点（VFN）已默认启用共识观察者。
  不建议更改验证者和 VFN 的共识观察者配置。
</Aside>

## 配置共识观察者

<Aside type="caution" emoji="❗">
  **最低硬件要求**<br />
  共识观察者默认未在 PFN 上启用，因为它要求节点满足[最低硬件要求](/zh/network/nodes/full-node/pfn-requirements#硬件要求)。
  如果节点资源不足且不满足这些要求，启用共识观察者会导致性能下降，因为它比传统状态同步需要更多 CPU。仅当节点满足最低硬件要求时才启用共识观察者。
</Aside>

### 启用共识观察者

要在 PFN 上启用共识观察者，请将以下内容添加到节点配置文件：

```yaml filename="fullnode.yaml"
consensus:
  enable_pre_commit: false

consensus_observer:
  observer_enabled: true
  publisher_enabled: true
```

### 禁用共识观察者

要在 PFN 上禁用共识观察者，请将以下内容添加到节点配置文件：

```yaml filename="fullnode.yaml"
consensus:
  enable_pre_commit: true

consensus_observer:
  observer_enabled: false
  publisher_enabled: false
```
