## 网络概览

1. [Localnet](http://127.0.0.1:8080)：用于本地开发的独立工具，基于已知版本的代码库运行，不依赖外部网络。
2. [Devnet](https://api.devnet.aptoslabs.com/v1/spec#/)：面向社区的共享网络；数据每周重置，并每周从 aptos-core 主分支更新。
3. [Testnet](https://api.testnet.aptoslabs.com/v1/spec#/)：面向社区的共享网络；数据会保留，网络配置将模拟 Mainnet。
4. [Mainnet](https://api.mainnet.aptoslabs.com/v1/spec#/)：承载真实资产的生产网络。

<details>
  <summary>代币供应量 API 更新</summary>
  2024 年 12 月 12 日，Aptos Foundation 更新了当前代币供应量 API。更新后的 API 会以当前月度周期开始时的流通量更新主网当前流通供应量，因此能更准确地反映主网流通量；旧版 API 报告的是上一个月度周期的流通量。网络的流通量计划没有变化，流通量仍与[此处](https://aptosnetwork.com/currents/aptos-tokenomics-overview)公布的原始代币经济模型一致。
</details>
