每个 Aptos 版本均可在 [Aptos-core releases](https://github.com/aptos-labs/aptos-core/releases) 的 GitHub 页面找到。每个版本均由以下 git 分支镜像：

- [最新 Mainnet 版本](https://github.com/aptos-labs/aptos-core/tree/mainnet)
- [最新 Testnet 版本](https://github.com/aptos-labs/aptos-core/tree/testnet)
- [最新 Devnet 版本](https://github.com/aptos-labs/aptos-core/tree/devnet)

每个 Testnet 和 Mainnet 版本发布前，Aptos 通常会进行多次 Devnet 发布。因此 Devnet 版本使用提交哈希而非版本号进行追踪。Testnet 和 Mainnet 版本通常一一对应，即每个 Testnet 版本都会进入 Mainnet。

热修复是例外情况，可能在 Mainnet 发生以处理生产环境中的紧急问题。详情请参阅 [Aptos 发布流程](https://github.com/aptos-labs/aptos-core/blob/main/RELEASE.md)。

## 更新节点

如果您是节点运营者，请使用新版本[更新节点](/zh/network/nodes/full-node/modify/update-fullnode-with-new-releases)。

## 订阅发布公告

### 通过 GitHub 订阅

1. 前往 [aptos-labs/aptos-core](https://github.com/aptos-labs/aptos-core) 仓库。
2. 打开 **Watch** 菜单并选择 **Custom**。
3. 选中 **Releases** 复选框，然后单击 **Apply**。

### 通过 [Aptos Discord](https://discord.gg/aptosnetwork) 订阅

加入 Aptos Discord 服务器，与我们和社区互动。我们也会在以下频道发布即将发布的版本：

- [#mainnet-release](https://discord.com/channels/945856774056083548/1042502400507916349)
- [#testnet-release](https://discord.com/channels/945856774056083548/1025614160555413545)
- [#devnet-release](https://discord.com/channels/945856774056083548/956692649430093904)

### 通过 [Aptos Twitter](https://x.com/AptosRelease) 订阅

在 Twitter 上关注 [@AptosRelease](https://x.com/AptosRelease)，获取即将进行的 Mainnet 发布的最新信息，并在需要更新节点时收到通知。[@AptosRelease](https://x.com/AptosRelease) 每隔几天会发布倒计时，提醒您更新至最新版本。_注意：这里不会发布热修复信息！_
